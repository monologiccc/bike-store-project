# bike-store-project

# Bike Store SQL & Python Analytics Project

Pet-проект: анализ данных сети веломагазинов с применением SQL и Python для статистических расчетов и визуализации.

## Датасет
[Bike Store Relational Database](https://www.kaggle.com/datasets/dillonmyrick/bike-store-sample-database)
с Kaggle. Использованы 7 таблиц: customers, orders, order_items, products, stores, brands, categories. Период данных: 2016-01 – 2018-12 (с оговоркой
по качеству данных за последние месяцы — см. раздел "Ограничения данных").

## Ключевые выводы

**Метрики и сегментация клиентов**
- Общая выручка за период — $7,689,116.56, средний чек (AOV) — $4,761.06
- Выручка сильно сконцентрирована: магазин Baldwin Bikes даёт ~68% всей выручки сети
- Mountain Bikes — самая продаваемая категория, почти вдвое опережает Road Bikes; структура спроса по категориям устойчива между магазинами
  (везде Mountain Bikes даёт ~35-36% выручки, несмотря на разный масштаб самих магазинов)
- LTV распределён с сильным правым хвостом: медиана $3,860 против среднего $5,321 — небольшая группа клиентов формирует непропорционально большой
  объем выручки (топ-5 клиентов — $31,900–$34,800 каждый)

**Воронка заказов**
- Общая конверсия "заказ создан → выполнен" — 89.5%, отклонено всего 2.8% заказов
- Между магазинами разброс rejection rate большой: у Rowlett Bikes — 10.9%, у Baldwin Bikes — 1.3% (почти в 4 раза меньше) — стоит разобраться в причине отклонения заказов именно в этом магазине

**Retention**
- 75% клиентов совершают только одну покупку за весь период наблюдений — ожидаемо для категории товара с длинным циклом повторной покупки
- В среднем по когортам возвращается ~9% клиентов; помесячная когортная сетка для этой категории малоинформативна из-за редкости повторных покупок

**A/B-тест (синтетический эксперимент)**
- Смоделированный эффект скидки (+8% к AOV) не был обнаружен как статистически значимый при сбалансированном разбиении групп: p=0.800, Cohen's d≈0.013
- Причина — высокая дисперсия выручки по отдельному заказу; power-анализ показал, что для надёжного обнаружения эффекта такого размера
  потребовалось бы ~99,000 заказов на группу.

## Ограничения данных
- После марта 2018 данные содержат аномалию: апрельский всплеск в необработанных заказах и только единичные Rejected-заказы до конца
  года (месяц 2018-05 вообще не содержит ни одного заказа) — похоже на технический хвост датасета, а не на реальную активность. Графики динамики
  выручки в этом проекте ограничены периодом до 2018-03 во избежание искажений
- A/B-тест смоделирован на реальных исторических данных — в датасете нет данных о реальных экспериментах
